# Talos Animate is now part of Talos Suite

The project is being consolidated under **[Talos Suite](TALOS_SUITE.md)**, a private, JavaScript-first suite for Three.js animation and Blender asset production.

[Visit the current project page](TALOS_SUITE.md) for its scope, integration status and legacy-editor screenshots. The original Godot tooling is retained as legacy compatibility; it is no longer the main product direction.

This compatibility page preserves older portfolio links. It is not a public source or build download.
